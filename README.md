# Operating Systems Lab

A comprehensive repository for Operating Systems laboratory experiments and curriculum topics.

## Table of Contents
* [Experiments](#experiments)
* [Theoretical Topics](#theoretical-topics)

## Experiments

### Process & IPC
* **Pipes**: Process creation and communication.
* **Shared Memory**: Multi-process memory sharing.
* **Message Queues**: Message-based communication.

### Synchronization & Deadlocks
* **Producer-Consumer**: Semaphore-based implementation.
* **Banker's Algorithm**: Deadlock avoidance simulation.

### Scheduling Algorithms
* **CPU Scheduling**: FIFO, SJF, Priority, Round Robin.
* **Disk Scheduling**: FCFS, SSTF, SCAN, CSCAN, LOOK, CLOOK.

### Memory & Filesystem
* **Paging**: Basic memory management simulation.
* **Page Replacement**: FIFO, LRU, Optimal algorithms.
* **File Allocation**: Sequential, Indexed, Linked strategies.

## Theoretical Topics
* Process communication mechanics
* CPU scheduling modeling
* Shared memory protocols
* Critical section resolution
* Deadlock avoidance design
* Memory management modeling
* Page replacement efficiency
* Storage allocation structures
* Disk head optimizations
